#  Weather Application

A web-based weather application that allows users to search for weather information by city.

##  Features

- Search weather information by city
- Display current temperature and weather conditions
- Show weather-related details such as humidity, pressure, and wind
- Dynamic weather icons
- API integration for retrieving weather data
- PHP and MySQL integration for storing weather-related data

##  Technologies Used

- HTML
- CSS
- JavaScript
- PHP
- MySQL
- Weather API

##  How It Works

1. The user enters a city in the search field.
2. JavaScript processes the search request.
3. Weather information is retrieved through the weather API.
4. The application displays the weather information to the user.
5. PHP and MySQL are used to handle stored weather data.
